# 까불 카페 랜딩 페이지

"오늘도 한 잔의 여유" — 까불 카페를 소개하는 한 페이지짜리 정적 랜딩 페이지입니다.

- 배포 주소: https://1978kwss.github.io/cafe-landing/
- 호스팅: GitHub Pages (`main` 브랜치, 루트 `/`)

## 폴더 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 페이지 본문 (상단 메뉴, 히어로, 대표 메뉴, 카페 이야기, 오시는 길, 푸터) |
| `style.css` | 페이지 스타일 (갈색 톤 디자인, 메뉴 카드 hover 효과) |
| `README.md` | 이 폴더에 대한 설명 문서 |

## 페이지 구성

1. **상단 네비게이션** — 메뉴 / 소개 / 오시는 길
2. **히어로** — 대표 문구와 "메뉴 보러가기" 버튼
3. **대표 메뉴** — 까불 라떼, 콜드브루, 수제 치즈케이크
4. **까불 카페 이야기** — 카페 소개
5. **오시는 길** — 주소, 영업시간, 전화 (현재 예시 값)

## 로컬에서 보기

빌드 과정이 없는 순수 HTML/CSS 프로젝트입니다. `index.html`을 브라우저로 열면 바로 확인할 수 있습니다.

## 배포

`main` 브랜치에 push 하면 GitHub Pages가 자동으로 다시 빌드해 반영합니다.
